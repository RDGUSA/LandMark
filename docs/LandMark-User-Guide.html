LandMark is a small Windows app for reading and writing Markdown, the plain-text format with # for headings and ** for bold, and for getting it into emails and Word documents without losing the formatting. You type on the left and see the finished document on the right, in the RDG style.

Copy for Email

Paste into Outlook or Gmail with headings, lists, tables and links intact.

Word document

Real Word styles (Heading 1, List Paragraph, Quote), so it stays easy to edit.

PDF document

Exactly what the preview shows, on US Letter pages, numbered "Page n of N".

Plain text

Symbols removed and headings underlined, for anywhere formatting won't go.

Getting Started

What you need

  • LandMark.exe. One file of about 1.8 MB. Keep it in a folder you won't move, such as Documents\Apps, and run it from there.
  • Windows 10 or 11 (64-bit) with the .NET 10 Desktop Runtime. If the runtime is missing, Windows says so when you start LandMark and links to the free download.
  • The Microsoft Edge WebView2 Runtime for the preview and PDF export. It comes with Windows 11 and with Microsoft Edge on Windows 10. If it's missing, the Preview pane says where to get it.

Opening a document

  • File › Open (Ctrl+O), or drag a .md file onto the window.
  • File › Open Recent lists the last 7 files you opened or saved, newest first.
  • Double-click a .md file in File Explorer, once you've set that up (see below).
  • Or start a new document (Ctrl+N) and type or paste Markdown into the editor.

A file that's already open in a LandMark window is never opened twice. Opening it again brings the window that has it to the front, and opening the window's own file just says "… is already open" in the status bar. Any other file opens in a window of its own.

Saving

File › Save (Ctrl+S) writes the Markdown back to the file, and Save As (Ctrl+Shift+S) saves a copy somewhere else. A yellow dot beside the file name means there are unsaved changes. It goes away when you save, or when you undo back to the saved text. If you close a window with unsaved changes, LandMark asks first.

Open .md files by double-clicking

Choose Help › Open .md Files with LandMark…. This registers LandMark for .md, .markdown, .mdown and .mkd files for your account only, with no admin rights needed.

  • If no other app has claimed those file types, LandMark becomes their default straight away.
  • Otherwise LandMark offers to open Settings › Apps › Default apps. Windows only lets you change a default yourself, so select .md there and choose LandMark.
Tip

Do this from LandMark.exe in the folder where you'll keep it. If you move the exe later, run it once from the new folder and the registration follows it.

  2. Outline (Ctrl+Shift+O). The document's headings; click one to go to it. The heading you're working under is highlighted.
  3. Markdown editor. Where you type. Double-click the word Markdown to show only the editor; double-click again for both panes.

  5. Unsaved dot and file name . The dot means there are changes you haven't saved. Point at the name to see the full path.
  6. Syntax colors. Headings, lists, bold, code, links and quotes each get their own color, so the Markdown is easy to scan.
  7. Line marker . The red bar beside the preview shows where the editor's cursor line is in the document.
  8. Preview, with the word count and the document's style. Double-click Preview to show only the preview.
  9. Status bar. The file's full path, with its own unsaved dot. Right-click the path to copy it. Short confirmations appear here for a few seconds.
  10. RDG ellipsis. The RDG Planning & Design mark.

Writing Markdown

Markdown is ordinary text with a few symbols for formatting. LandMark shows the result as you type. Press F1 (View › Markdown Cheat Sheet) for a panel that explains each symbol. Click an example in the panel to insert it: selected text is wrapped in it, and headings, lists and quotes apply to the current or selected lines.

Type thisTo get
# Heading 1
## Heading 2
### Heading 3		Headings, from the title down. Each extra # is one level smaller, down to ######. Put a space after the #.
**bold**Bold (or __two underscores__)
*italic*Italic (or _one underscore_)
***bold italic***Bold and italic
~~strikethrough~~Crossed-out text
`code`Code in a monospace font. Use the backtick ` (left of 1), not the apostrophe.
- itemA bullet list. A dash (or * or +) and a space at the start of each line.
1. itemA numbered list, counting up from the first number.
  - nested itemIndent two or more spaces under an item to nest a list inside it.
- [ ] to do
- [x] done		A checklist: an open box, and a checked one.
[text](https://…)A link: the words to show, then the address. A web address on its own becomes a link too.
![description](image.png)An image. The description is shown wherever the image can't be.
> quoted textA block quote, indented with a colored bar.
```
code block
```		A block of code: three backticks on the lines before and after.
---A horizontal rule, on a line of its own with a blank line above. Directly under text, it makes that text a Heading 2 instead.
| A | B |
|---|---|
| 1 | 2 |		A table. Pipes separate the columns and the dashes mark the header row. In the dashes row, :--- aligns left, :---: centers and ---: aligns right.
(a blank line)A new paragraph. A single line break inside a paragraph is joined into one line.
two spaces at the end of a lineA line break without starting a new paragraph (a \ at the end works too).
\*A backslash before a symbol shows the symbol itself instead of formatting.

HTML tags typed into the text are left out, except <br> for a line break.

Find and Replace

Press Ctrl+F to find, or Ctrl+H to find and replace. It works from either pane and in any view.

  • The bar opens above the editor, or above the preview in Preview Only. It starts with any text you've selected, and goes straight to the first match.
  • The count shows where you are, such as 1 of 28. ? of 28 means there are matches but none is selected, and No results means there are none.
  • The current match is selected in the editor. In the preview, every match is highlighted in yellow and the current one in orange.
  • Enter or F3 goes to the next match, and Shift+Enter or Shift+F3 to the previous one. Searching wraps around, and the status bar says when it does.
  • Aa (Alt+C) matches upper and lower case exactly, and ab (Alt+W) finds whole words only.
  • The arrow  at the left shows or hides the Replace row. Replace changes the current match and moves to the next, and Replace All (Ctrl+Alt+Enter) changes every match at once. Ctrl+Z undoes a Replace All in one step.
  • Esc closes the bar.

Find searches the Markdown, so a search for a link's address finds it even though the preview only shows the link's words.

Email, Word, PDF and Plain Text

Everything you send uses the document's style: the fonts, sizes and colors you see in the preview.

CommandShortcutWhat you get
Edit › Copy for EmailCtrl+Shift+C The formatted document on the clipboard, ready to paste into a new message. The formatting is built in, so Outlook and Gmail keep it, and programs that only take text get a plain version.
Edit › Copy as Plain TextCtrl+Alt+C Text without the Markdown symbols. Headings are underlined, and link addresses are kept in parentheses.
File › Export › PDF DocumentCtrl+E The preview printed to US Letter pages, with "Page n of N" at the bottom. It looks exactly like the preview, links can be clicked and text can be selected.
File › Export › Word Document A .docx that uses Word's own styles (Heading 1–6, List Paragraph, Quote, Hyperlink), so it's easy to keep editing in Word.
File › Export › Plain Text The plain-text version, saved as a .txt file.

Format › Page Margins sets the margins for PDF and Word exports: Wide (1″) or Narrow (0.25″) on every side. Narrow is fine on screen, but some printers can't print that close to the edge.

Images in exports

Pictures from your PC appear in the preview and the PDF. In Copy for Email they become [Image: description], because a path on your PC means nothing to the recipient. In Word and plain-text exports they also appear as [Image: description].

Links and Images

Clicking links in the preview

  • Web and email links open in your browser or email app.
  • Links to other Markdown files open in LandMark. Addresses that don't start with a drive or https:// are relative to the document's folder, so save a new document first.
  • Other files and folders open in their usual Windows program.
  • For safety, programs (.exe, .bat, .ps1 and the like) are never started from a link.
  • If a link's target doesn't exist, the status bar says so.

Pictures from your PC

Write ![Site plan](images/site-plan.png) to show a picture. A path like that one is relative to the document's folder, so a new document needs saving first. A full path such as C:\Projects\photo.jpg works too.

Styles and the App Theme

Markdown has no fonts or colors of its own. Those come from the document's style, which is used by the preview, Copy for Email, PDF and Word export. The Preview header shows the current one, such as Style: RDG.

Built-in styles

RDG default

Franklin Gothic in True Black, RDG Red accents on quotes and rules, from the April 2026 Brand Guidelines.

Classic

Calibri with Word-style blue headings.

Neutral

Black and gray only; safe for any business email.

The Format menu

  • Pick a style for the current document. LandMark remembers it for that file.
  • Set Current Style as Default uses it for new documents and for files without a style of their own.
  • Customize Styles… opens the Styles window (below).
  • Page Margins: Wide or Narrow, for exports.
  • App Theme: System (follow Windows), Light or Dark. This changes LandMark's own look, not your documents. The preview stays white because it shows what your readers will see.

Making your own style

In Format › Customize Styles…:

  • New starts from the RDG style, Duplicate copies the selected style, and Delete removes one. Built-in styles can't be changed, so duplicate one to make an editable copy.
  • You can set the name, the text font, size and color, fonts, colors and sizes for Headings 1–2 and 3–6, bold headings, link, accent and quote colors, and the table header fill, table borders, code font and code background.
  • Use for This Document saves your styles and applies the selected one. Save saves them without changing the document, Set as Default makes the selected one the default, and Cancel throws away the changes, including deletions.
Fonts

Each font setting is a list in order of preference, separated by commas, such as FranklinGothicITC Book, Franklin Gothic Book, Arial. LandMark uses the first one installed on the PC, because Outlook only honors the first font in a list. Install the brand fonts from the RDG Branding folder to get Franklin Gothic ITC.

When Someone Else Changes the File

LandMark doesn't lock the file you have open, so another program or a colleague on a shared drive can change it while it's open. LandMark notices straight away. If you're in another program at the time, it waits until you switch back.

If you haven't changed anything

LandMark asks whether to Reload the new version or keep the one shown with Not now.

If you have unsaved changes too

ChoiceWhat happens
MergeKeeps both: their changes and yours, line by line. The result stays unsaved for you to check.
ReloadReplaces your version with the file on disk.
Not nowKeeps your version for now. Yellow buttons stay beside the file name until you're ready.

Merging and reloading are each a single step you can undo: Ctrl+Z brings back exactly what you had, and Ctrl+Y redoes it.

The yellow buttons

After Not now, these stay at the top of the Markdown pane, or the Preview pane in Preview Only:

 Site Visit Notes.md

  •  Merge brings in their changes and keeps yours. It only appears while you have unsaved changes.
  •  Reload replaces your version with the file on disk.

If you save before choosing, LandMark asks first (Replace the changes on disk?), so the other changes aren't overwritten by accident.

When you both changed the same lines

Merge can't choose for you there, so it keeps both versions between marker lines and selects the first such place:

The client asked us to keep the lobby flexible.
<<<<<<< Your changes
Meeting moved to Thursday at 10.
=======
Meeting moved to Friday at 2.
>>>>>>> Version on disk
Next steps follow.

Keep the lines you want, delete the rest along with the three marker lines, then save. To find each place, search for <<<<<<< with Ctrl+F. If any markers are still there when you save, LandMark asks first and Show me takes you to them.

If the file is deleted or moved

The text stays open and counts as unsaved. The status bar adds (deleted or moved) after the path. Save (Ctrl+S) to put the file back, or use Save As to keep it somewhere else.

Settings and Other PCs

LandMark keeps its settings for each PC in %AppData%\LandMark. Type that into the File Explorer address bar to open the folder, or follow the link in Help › About LandMark.

  • settings.json: the app theme, page margins, Syntax Colors and the Open Recent list.
  • styles.json: your own styles, the default style, and the style chosen for each file.
  • WebView2: the preview's browser cache. You don't need to copy it.

To use LandMark on another 64-bit Windows 10 or 11 PC, copy LandMark.exe there. To bring your own styles along, also copy styles.json into %AppData%\LandMark on the other PC.
